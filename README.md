# AI Ready Suite

> 帮助团队评估设计系统的 AI 就绪程度，发现改进方向。

**⚠️ 本项目公开内容为功能说明。完整的评估方法论、评分算法和报告引擎为专有资产，未在公开仓库中披露。**

---

## 它能做什么

- **评估** — 对设计系统进行多维度的 AI 就绪度分析
- **分析** — 定位影响 AI 可用性的关键瓶颈
- **建议** — 输出分阶段的改善路径

具体评估维度、评分标准和权重体系为内部资产。对外输出以定性分析和改善建议为主。

---

## 快速开始

```bash
cd mcp-servers/ai-ready-engine && npm install && cd ../..
node test/run-assessment.js
```
